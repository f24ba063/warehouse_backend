ログイン再実装計画（Spring Security前提）
1. 目的の明確化

倉庫管理アプリでユーザー認証を復活させる

権限に応じて画面・操作制御を可能にする

セキュリティ基準に沿ったパスワード管理

2. 構成方針

バックエンド: Spring Boot + Spring Security

フロント: React（ログインフォームを用意、API連携）

DB: ユーザー情報管理（username, password, role, enabled）

3. 認証戦略

ユーザーの認証情報を DB から取得

パスワードはハッシュ化して保存

認証成功時はセッションまたは JWT を利用して状態管理

認証失敗時はフロントに明確にエラーを返す

4. 権限管理戦略

画面・APIごとにアクセス権を設定

roleに基づいて機能制御

将来的に管理者・通常ユーザー・ゲストなど階層拡張を想定

5. UI連携戦略

フロントでのフォーム送信 → バックエンドで認証

成功 → ダッシュボードなどのトップ画面に遷移

失敗 → エラーメッセージ表示

CSRF 対策・セッション管理を適切に組み込む

6. 移行・安全対策

既存ユーザーがいる場合はハッシュ化方式の統一

強制パスワード変更や初期パスワード管理ルールを検討

不正アクセスやブルートフォース対策の検討（ログイン試行制限など）
